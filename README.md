# Mở Đường VN — Android

Mã nguồn ứng dụng Android của dự án mã nguồn mở Mở Đường VN. Ứng dụng đang được phát triển; phạm vi và hành vi có thể thay đổi trong các phiên bản tiếp theo.

## Build

Yêu cầu JDK 17 và Android SDK Platform 37. SDK location có thể được cấu hình qua `ANDROID_HOME` hoặc `local.properties` (file này đã được gitignore).

```sh
./gradlew :app:assembleDebug
```

## Tham gia

Mở issue trong repository để đề xuất thay đổi hoặc báo lỗi, rồi gửi pull request sau khi phạm vi đã được trao đổi.
